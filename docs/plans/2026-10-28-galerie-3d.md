# Galerie des matchs en 3D : plan de travail

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes se cochent (`- [ ]`).

**Objectif :** remplacer le couloir CSS de la galerie par un musée Three.js lumineux. Mini Cycy et Kevin, de dos, y visitent les 14 matchs ; chaque tableau a un « En savoir plus » qui ouvre un panneau souvenirs.

**Architecture :**
- Un écran `museum3dScreen`, chargé à la demande (`import()`) par `main.js`, avec la même interface que l'écran CSS. L'écran CSS (`js/museum.js`) reste en secours.
- Le défilement natif, aimanté par étape, pilote un ressort (`rail.js`, mathématiques pures, testées sous Node). Le ressort donne la pose de la caméra et des avatars.
- La scène (`room.js`, `decor.js`, `visitors.js`) est construite en code, avec des textures dessinées en canvas (`textures.js`).

**Stack :** HTML, CSS et JS natifs (modules ES), sans build ; Three.js r170 copié dans `js/vendor/` ; GSAP 3.12.5 (`window.gsap`) ; `node:test` ; puppeteer-core pour les tests de bout en bout.

**Spec :** `docs/specs/2026-10-28-galerie-3d-design.md`

### Tâche 2 : le rail et le ressort (mathématiques pures)

**Fichiers :**
- Créer : `js/gallery3d/rail.js`
- Test : `tests/rail.test.mjs`

**Interfaces :**
- Produit :
  - `ROOM = { width: 8, height: 4.4, spacing: 6, eyeY: 1.55, frameW: 1.9, frameH: 1.45, paintingY: 2.05, cartelY: 0.98, cartelW: 1.3, cartelH: 0.5, visitorsGap: 2.2, visitorH: 1.15 }`. Ce sont des valeurs de départ, à ajuster d'après les captures de la tâche 4.
  - `stopLayout(count, room = ROOM) → Array<{ index, z, side, wallX }>`, avec `z = −(index + 1)·spacing`, `side = index % 2 ? 1 : −1` et `wallX = side·width/2`.
  - `framingDistance(aspect, vfovDeg, room = ROOM) → number` : distance caméra–mur. Le tableau doit tenir dans 86 % de la largeur visible, et le bloc du haut du tableau jusqu'au bas du cartel dans 62 % de la hauteur. Bornée à `[2.5, width − 0.6]`.
  - `zoomDistance(aspect, vfovDeg, room = ROOM) → number` : le tableau fait 95 % de la largeur.
  - `railPose(c, count, aspect, vfovDeg, zoom = 0, room = ROOM) → { cam: { x, y, z, yaw, pitch }, visitors: { x, z, yaw }, focus, stop }`. La caméra regarde vers `(−sin yaw, 0, −cos yaw)`.
  - `springStep({ x, v }, target, dt, { stiffness = 90, damping = 0.85 } = {}) → { x, v }`.

```js
import { ROOM, stopLayout, framingDistance, zoomDistance, railPose, springStep } from "../js/gallery3d/rail.js";

test("rail: paintings alternate left and right, one spacing apart", () => {
  const stops = stopLayout(14);
  assert.equal(stops.length, 14);
  assert.deepEqual(stops.slice(0, 3).map((s) => s.side), [-1, 1, -1]);
  assert.equal(stops[1].z - stops[0].z, -ROOM.spacing);
  assert.equal(stops[0].wallX, -ROOM.width / 2);
});

test("rail: framing fits phones held upright and stays inside the room", () => {
  for (const aspect of [393 / 852, 375 / 667, 1440 / 900]) {
    const d = framingDistance(aspect, 55);
    assert.ok(d >= 2.5 && d <= ROOM.width - 0.6, `${aspect}: ${d}`);
    assert.ok(zoomDistance(aspect, 55) < d);
  }
  assert.ok(framingDistance(393 / 852, 55) > framingDistance(1440 / 900, 55));
});

test("rail: walking looks down the corridor, a stop faces its painting", () => {
  const walk = railPose(1.5, 14, 0.46, 55);
  assert.equal(walk.focus, 0);
  assert.ok(Math.abs(walk.cam.yaw) < 1e-9 && Math.abs(walk.cam.x) < 1e-9);
  const left = railPose(1, 14, 0.46, 55); // painting 0, left wall
  assert.equal(left.focus, 1);
  assert.equal(left.stop, 1);
  assert.ok(Math.abs(left.cam.yaw - Math.PI / 2) < 1e-9);
  assert.ok(Math.abs(left.cam.z - stopLayout(14)[0].z) < 1e-9);
  assert.ok(left.visitors.x < left.cam.x && left.visitors.x > -ROOM.width / 2); // between the camera and the wall
  assert.ok(Math.abs(railPose(2, 14, 0.46, 55).cam.yaw + Math.PI / 2) < 1e-9);
  assert.ok(railPose(1, 14, 0.46, 55, 1).cam.x < left.cam.x); // zoomed in: closer to the left wall
  assert.equal(railPose(0, 14, 0.46, 55).focus, 0); // entrance
  assert.equal(railPose(15, 14, 0.46, 55).focus, 0); // the end
});

test("rail: the spring settles on its target, overshooting by 5 % at most", () => {
  let s = { x: 0, v: 0 };
  let max = 0;
  for (let t = 0; t < 2.5; t += 1 / 60) {
    s = springStep(s, 3, 1 / 60);
    max = Math.max(max, s.x);
  }
  assert.ok(Math.abs(s.x - 3) < 0.01);
  assert.ok(max < 3 * 1.05);
  assert.deepEqual(springStep({ x: 1, v: 0 }, 1, 0.5), { x: 1, v: 0 }); // at rest it stays put, dt clamped
});
```
