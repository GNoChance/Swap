# Cycy et Kevin

Le portail de Cycy et Kevin : un hub (carrousel) ouvre trois mondes.
- **Le Swap** : le swap de 9 cadeaux, chacun caché derrière un mini-jeu, débloqués dans l'ordre (le site d'origine, « Swap de Cyrielle »).
- **La Galerie UBB** : le musée des matchs, avec ses souvenirs partagés.
- **Nos aventures** : le passeport de nos 15 sorties (coquille pour l'instant ; design `docs/specs/2026-10-29-portail-cycy-et-kevin-design.md`).

- Dossier : `C:\Users\eliott.colin\swap-cyrielle`
- **Portail** (2026-10-29, plan `docs/plans/2026-10-29-hub-navigation.md`) : adresses après un `#` (`js/router.js`) : `#/` le hub, `#/swap`, `#/ubb`, `#/aventures`, `#/aventures/<id>` ; une adresse inconnue mène au hub. Le hub (`js/hub.js`, calculs dans `js/hub-logic.js`) retient la dernière carte (`swap-cyrielle:hub`). On entre par la carte qui s'agrandit en plaque, on revient par la plaque qui se replie (`js/plate.js`). Quitter le swap recharge la page (ses minuteries ne survivent pas à un départ) ; le drapeau `swap-cyrielle:fold` fait démarrer le hub plaque repliée dans la carte du Swap. Icône « Cycy et Kevin » : `node tools/icone/render.mjs` (dessin dans `tools/icone/icone.html`), sur l'iPhone retirer l'ancienne icône de l'écran d'accueil et la rajouter
- **Tests de bout en bout** (`tests/e2e/`, hors de `npm test`) : lancer `node tests/e2e/serve.mjs` (petit serveur sur le port 5173 ; `npm run dev` abandonne en EMFILE sous une série complète), puis `node tests/e2e/hub.mjs` (trois écrans, 19 vérifications chacun ; `ONLY=PC` pour un seul écran, `SHOTS=<dossier>` garde une capture du hub). Chrome sans interface piloté par `tests/e2e/cdp.mjs` (client CDP maison, sans dépendance ; `CHROME=<chemin>` si Chrome n'est pas à sa place habituelle)
- Stack : HTML/CSS/JS vanilla (modules natifs), GSAP 3.12.5 copié dans `js/vendor/`, pas de build
- Planches sources des stickers : `planches/swap/`, `planches/ubb/` (maillots, Dédé et Nini, stickers de dos), `planches/voyages/` (les prochaines) ; hors git, seulement sur le PC de l'utilisateur. Les stickers découpés utilisés par le site sont dans `assets/cyrielle/`
- Tampons de « Nos aventures » : `assets/aventures/tampons/<id>.svg` (+ `tampons.json` : nom, encre, inclinaison), produits par `node tools/tampons/generate.mjs` (la liste est en tête du fichier ; texte converti en tracés avec les polices OFL de `tools/tampons/fonts/`). Aperçu : ouvrir `tools/tampons/apercu.html`
- Hébergement prévu : Vercel (repo git créé par l'utilisateur, URL pas encore fournie ; ne rien pousser sans son accord)
- Appareil de jeu : iPhone 17 (Safari) de l'utilisateur. Cyrielle a un Android mais jouera sur l'iPhone
- Lancer en local : `npm run dev` puis http://localhost:5173 (tests : `npm test`). Pour refaire la grille de mots croisés si l'utilisateur change les mots : chercher une disposition compacte (script de recherche à réécrire, il était dans le scratchpad), puis vérifier avec `npm test`
- Adresses spéciales : `?demo` débloque tout sans rien enregistrer, `?reset` efface la progression, `?pub` = la pub, `?debrief` = ses réponses au débrief, `?secret` = la fin secrète (rien n'est enregistré), `?ubb` = la surprise UBB seule (rien n'est enregistré), `#/ubb` = la galerie des matchs (en 3D ; l'ancienne adresse `?musee` y mène), `?css#/ubb` = sa version de secours sans 3D, `?souvenirs=fake#/ubb` = les souvenirs sur un faux serveur local (code `test-code`), `?rejouer` = tout le swap depuis l'intro sans rien enregistrer (bouton « Tout rejouer » de l'accueil), **`?test` = page de test avec un raccourci vers chaque scène** (`?demo&scene=intro|gift-1…9|bonus|final|debrief|map`, `&snack=brets` possible)
- Le réglage iPhone « Réduire les animations » est volontairement ignoré (`const reduced = false` dans les scripts) : avec lui, Mini Cyrielle revenait avec ses chips en un clin d'œil

### Déroulé
- **Accueil** : fond crème papier légèrement texturé, message, bouton pour commencer (ce premier toucher active les sons sur iPhone).
- **Timeline** : chemin vertical qui serpente. **Seuls les cadeaux débloqués sont affichés** (demande de l'utilisateur, 2026-10-26) : au départ on ne voit que le cadeau 1. Après « J'ai ouvert mon cadeau », le chemin se dessine vers un emplacement vide, puis le cadeau suivant apparaît (fondu + cachet qui éclate). États visibles : en cours (pulse doré), terminé (✦ + nom du cadeau). Le jalon final « Un dernier mot » n'apparaît qu'une fois les 9 ouverts. En `?demo` tout est débloqué donc tout est visible : tester l'apparition progressive sur l'adresse normale (+ `?reset`).
- **Étape** : panneau qui monte du bas sur mobile, fenêtre centrée sur PC. « Cadeau n°X — titre », énigme, jeu, « Besoin d'un indice ? » si l'étape en a un, « Voir la réponse » toujours disponible mais discret. Après réponse trouvée ou dévoilée : animation, phrase de révélation, « file ouvrir le paquet n°X », puis bouton « J'ai ouvert mon cadeau ♥ » qui valide et débloque la suite. Une étape terminée peut être rouverte pour revoir la réponse.
- **Final** : mot doux, récap des 9 cadeaux, score « trouvé toute seule » en clin d'œil, grand feu d'artifice puis pluie de cœurs.

Une énigme compte comme « trouvée toute seule » si elle est résolue avant d'appuyer sur « Voir la réponse ».

### Mise en place de Supabase (une fois, ~10 minutes)
1. Créer un compte gratuit sur [supabase.com](https://supabase.com), puis **New project** : un nom (« swap-cyrielle »), un mot de passe de base de données (n'importe lequel, garde-le), région **West EU (Paris)**.
2. **SQL Editor** → **New query** → coller tout le contenu de `supabase/setup.sql` → **Run**. Il crée les tables (souvenirs, photo du tableau), le stockage privé (50 Mo par fichier), les règles d'accès et le direct. On peut le relancer sans risque : **à relancer après chaque mise à jour de ce fichier** (dernière : 2026-10-29, table `covers`).
3. **Authentication** → **Sign In / Providers** → **Email** : désactiver **Allow new users to sign up** (personne ne peut se créer de compte).
4. **Authentication** → **Users** → **Add user** → **Create new user** : e-mail `famille@swap-cyrielle.app`, mot de passe = **le code** que vous taperez sur le site (8 caractères ou plus, une petite phrase c'est bien), cocher **Auto Confirm User**.
5. **Project Settings** → **API** : copier **Project URL** et la clé **anon public**, et les envoyer à Claude (ou les coller dans `js/souvenirs-config.js`). Ne jamais envoyer le code lui-même par écrit.

- **Supprimer un souvenir** : **Table Editor** → `souvenirs` → cocher la ligne → **Delete** ; puis **Storage** → `souvenirs` → le dossier du match (sa date) → supprimer ses fichiers (`<id>-full.jpg`, `<id>-thumb.jpg` ou la vidéo).
- **Changer le code** : **Authentication** → **Users** → supprimer le compte `famille@swap-cyrielle.app`, puis le recréer (étape 4) avec le nouveau code. Les souvenirs ne sont pas liés au compte, rien n'est perdu ; tous les téléphones devront taper le nouveau code. (« Reset password » enverrait un e-mail à une adresse qui n'existe pas.)
- **Place** : l'offre gratuite donne 1 Go de fichiers (des milliers de photos ; une vidéo prend jusqu'à 50 Mo). **Storage** montre l'espace utilisé.
